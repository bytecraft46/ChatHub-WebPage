# Chat Hub Landing Page

Official download and landing page for the **Chat Hub** Android application.

Website: [https://chathub-chattingapp.vercel.app](https://chathub-chattingapp.vercel.app)

## Project Structure

```text
├── index.html       # Main HTML markup
├── style.css        # CSS styles and responsive design
├── main.js          # Dynamic copyright year & scroll reveal animations
├── package.json     # Project dependencies and Vite build scripts
└── README.md        # Documentation
```

## Getting Started

### Option 1: Zero Installation
Simply double-click or open [index.html](file:///c:/chathub%20webpage/index.html) in any web browser.

### Option 2: Run with Vite Dev Server
```bash
npm install
npm run dev
```

### Option 3: Production Build
```bash
npm run build
```
This produces optimized production assets in the `dist` folder ready to deploy to Vercel, Netlify, or GitHub Pages.
